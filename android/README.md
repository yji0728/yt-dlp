# Android APK Implementation of yt-dlp

This directory contains the Android APK implementation of yt-dlp functionality.

## Features
- Download videos from supported sites
- Android native UI
- Background downloads with notifications
- Storage management
- Network handling

## Structure
- `app/` - Main Android application module
- `gradle/` - Gradle wrapper files
- `build.gradle` - Root build configuration
- `settings.gradle` - Project settings

## Build Instructions
1. Open in Android Studio
2. Sync project with Gradle files
3. Build APK: `./gradlew assembleDebug`

## Installation
Install the generated APK file on Android device or emulator.
